I/O is typically one of two models:
----------------------------------
Polling: CPU repeatedly polls an I/O device to see when data
is availible to input or output
Interrupts: The I/O device interrupts the CPU when its ready to
use I/O, the cpu saves the contect of the current task and runs 
a special *interrupt-service routine* to handle I/O device request and
then resumes the interrupted task

Good code should be written to be efficient for devices, and
readable for humans.
